> VideoFrame 是一个轻量级的桌面应用程序，用于从视频文件中提取关键帧。它基于Tauri 2 技术构建，具有极小的安装包体积和简洁的用户界面。

## 功能特点

- 🎥 从视频文件中提取关键帧
- 🖼️ 预览提取的关键帧图像
- 📦 极小的软件体积

### 从源代码构建

1. 克隆仓库：
   ```bash
   git clone https://github.com/ylei2024/videoframe.git
   ```
2. 安装依赖：
   ```bash
   npm install
   ```
3. 运行开发模式：
   ```bash
   npm run tauri dev
   ```
4. 构建应用：
   ```bash
   npm run tauri build
   ```
